# Nutzungsbedingungen – Private Volvo-evcc-Integration

**Stand:** 28. Oktober 2026

## 1. Zweck der Anwendung

Diese Anwendung dient der privaten Verbindung eines Volvo-Fahrzeugs mit der Open-Source-Software evcc zur Unterstützung des intelligenten Ladens von Elektrofahrzeugen, beispielsweise in Verbindung mit einer Photovoltaikanlage und Home Assistant.

Die Anwendung wird ausschließlich für den persönlichen Gebrauch des Betreibers eingerichtet und ist kein kommerzieller Dienst.

## 2. Zugriff auf Fahrzeugdaten

Nach ausdrücklicher Autorisierung durch den Fahrzeughalter kann die Integration über die Volvo Cars API bestimmte Fahrzeugdaten abrufen. Der Zugriff beschränkt sich auf die für die Integration erforderlichen Daten und Berechtigungen.

Die Daten werden zur Anzeige des Fahrzeugstatus und zur Unterstützung der Ladeplanung in evcc verwendet.

## 3. Verantwortungsvolle Nutzung

Die Anwendung darf nur mit einem Volvo-Konto und einem Fahrzeug verwendet werden, für deren Datenzugriff eine entsprechende Berechtigung besteht.

Der Betreiber ist dafür verantwortlich, seine Zugangsdaten und API-Schlüssel vertraulich zu behandeln.

## 4. Verfügbarkeit und Haftung

Die Integration wird ohne Garantie auf ununterbrochene Verfügbarkeit oder Fehlerfreiheit bereitgestellt. Änderungen oder Ausfälle der Volvo Cars API oder der verwendeten Software können die Funktion beeinträchtigen.

Die gesetzlichen Haftungsregelungen bleiben unberührt.

## 5. Datenschutz

Fahrzeugdaten dürfen nur für den vorgesehenen Zweck verarbeitet werden. Der Betreiber sollte die tatsächlichen Datenflüsse und die eingesetzten Dienste prüfen und sicherstellen, dass die geltenden Datenschutzbestimmungen eingehalten werden.

Diese Nutzungsbedingungen ersetzen keine gesonderten Datenschutzhinweise, soweit solche erforderlich sind.
